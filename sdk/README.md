# Arctix SDK (staged)

Everything you need to use ArctixC, split by language. Regenerated by
`ArctixC/build.ps1` on every build — do not edit files here by hand.

## C++ project — use `cpp/`

| File | What it is |
|---|---|
| `arctixc.hpp` | C++ API in **one header** (`#include "arctixc.hpp"`) |
| `arctixc_all.hpp` | C++ API **+ C ABI** in one header (same include) |
| `arctixc.lib` + `arctixc.dll` | Dynamic flavor: link the `.lib`, stage the `.dll` next to your exe |
| `arctixc_static.lib` | Static flavor: link it, define `ARCTIXC_STATIC`, no `.dll` at all |

Pick **one** flavor: DLL (shared, hot-swappable) or static (single exe).

## C project — use `c/`

| File | What it is |
|---|---|
| `arctixc_c.h` | C ABI in **one header**, pure-C safe |
| `arctixc_c.lib` + `arctixc_c.dll` | Link the `.lib`, stage the `.dll` next to your exe |

## `tests/` and `examples/`

All test runners and example programs, each shipped with the DLLs they
need beside them — double-click and they run. `StaticSmoke` needs no DLL
(static proof); `DllAmalgam` proves the single header works with the DLL.
